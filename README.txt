Single-page version of the personal website.

Navigation is now handled by js/navigation.js, so the page does not reload when changing tabs and the music player remains alive.

Required local assets:
- cat.jpeg in the project root
- audio/track1.mp3 through audio/track5.mp3 in the audio folder

Default music: track4.mp3 (Enchanting Stranger - Forza Horizon 6)
Default volume: 25%
